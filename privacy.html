Privacy Policy — Hermes YouTube

Last updated: 2026-10-11

"Hermes YouTube" is a private automation tool built and operated solely by the owner of the YouTube channel Thảo Nguyên Nihongo (@thaonguyennihongo2021) to manage that channel.

What the app accesses

With the channel owner's explicit authorization (Google OAuth), the app uses the official YouTube Data API v3 and YouTube Analytics API to:

  • read statistics and analytics of the owner's own channel and videos (views, watch time, impressions, click-through rate, revenue estimates);
  • update titles and descriptions of the owner's own videos.

How data is handled

  • All data is processed and stored only on the owner's own computer/server, for the sole purpose of improving the owner's lecture videos.
  • Data is never sold, shared, rented, or transferred to any third party.
  • The app does not collect data from any user other than the channel owner, and does not track visitors.
  • API credentials are stored in a restricted, non-public location on the owner's machine.

Revoking access

The owner can revoke the app's access at any time from Google Account permissions (remove "Hermes YouTube"). Revoking immediately stops all API access.

Contact

The channel owner, via the YouTube channel page: youtube.com/@thaonguyennihongo2021
