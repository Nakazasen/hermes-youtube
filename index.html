Hermes YouTube

Hermes YouTube is a private automation tool built and operated solely by the owner of the YouTube channel Thảo Nguyên Nihongo (@thaonguyennihongo2021), a Vietnamese channel teaching Japanese (Kanji N3 Soumatome series, N5 kana, N1 vocabulary).

The tool uses the official YouTube Data API v3 and YouTube Analytics API, with the channel owner's authorization, to:

  • read the channel's own statistics and analytics (views, watch time, impressions, click-through rate);
  • review lecture quality and keep a feedback log so lessons improve day by day;
  • update titles and descriptions of the channel's own videos to match the channel's naming standard.

It is a personal tool for a single channel owner. It is not a public service, it does not serve other users, and it does not collect data from visitors of this page.
